**Status counts:** ok 24 · not_found 0 · copyright_risk 0

**Method.** Every `textOriginal` was extracted programmatically (by anchor line) from a page fetched with curl, then cleaned only of zero-width joiners, trailing verse numbers and the source's inline variant markers (each removal is recorded in the item's `notes`). IAST was generated mechanically from the fetched Devanagari/Malayalam with the `indic_transliteration` library — nothing was typed from memory — and compared automatically against the check source's own romanization (normalised for ē/ō, ṁ/ṃ, ch/c and anusvara-vs-nasal). Meanings are original paraphrases.

**Caveats that apply to all items.**
- Transliteration follows the source's orthography, so anusvara spellings (e.g. `तरंग`) come out as `taraṃga` where other editions write `taraṅga` — same sound.
- `jyotirlinga-smaranam`, `puri` and `brahma` have real textual disagreements between sources (below); the sanskritdocuments reading was kept each time.
- `murugan-saravanabhava`, `ayyappan-saranam`, `sai-omsairam`, `shiva-panchakshara` are chants/mantras cited from descriptive sources, not verse editions.
